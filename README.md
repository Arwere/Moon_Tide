# 🌊 Moon Tide - Solana Memecoin Trading System

**Advanced multi-agent AI trading bot for Solana memecoins.**

Combines real-time technical analysis, Claude AI intelligence, and three specialized trading bots that dynamically select the best strategy for each opportunity.

---

## ✨ Key Features

- **Three Specialized Bots** with distinct personalities:
  - **TideTitan** → Strong trends & momentum
  - **DepthDestroyer** → High volatility & explosive moves
  - **LiquidityKraken** → Mean reversion & pullbacks

- **Dynamic Bot Selection** — Claude decides which bot is best in real-time
- **Hybrid Decision Engine** — Technical Analysis (45%) + Claude AI (55%)
- **Real-time Data** — DexScreener + Birdeye fallback
- **Jupiter Swap Integration** (Dry-run mode available)
- **Telegram Alerts** — Separate topics for decisions and trade executions
- **Risk Management** — Position limits, stop-loss, take-profit
