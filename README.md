# 🌊 Moon Tide - Solana Memecoin Trading System

**Advanced multi-agent AI trading bot for Solana memecoins.**

Combines technical analysis, real-time data, and Claude AI to make smart trading decisions with three specialized bots.

---

## ✨ Features

- **3 Specialized Bots** (TideTitan, DepthDestroyer, LiquidityKraken)
- **Dynamic Bot Selection** — Claude chooses the best bot for each opportunity
- **Hybrid Decision Engine** (Technical Analysis + Claude AI)
- **Real-time Data** from DexScreener + Birdeye
- **Jupiter Swap Integration**
- **Telegram Alerts** (separate topics for decisions & trades)
- **Safe Dry-Run Mode**
